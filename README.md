# landing-page-pes

Landing page de **PES Dépannage**, une plateforme de mise en relation entre
particuliers et artisans d'urgence — plomberie, serrurerie, électricité — avec
la promesse d'une réponse en moins de deux heures.

## La page

Une seule page, `index.html`, tout en un fichier : structure, styles et contenu.
Elle enchaîne l'accroche, le fonctionnement en quatre étapes (décrire le
problème, choisir un créneau, réponse de l'artisan sous deux heures,
intervention), les arguments — artisans certifiés et assurés, aucun frais caché,
avis vérifiés, plateforme locale — et un appel aux artisans qui voudraient
rejoindre la plateforme.

La typographie est Inter, chargée depuis Google Fonts. Rien d'autre n'est
appelé de l'extérieur : pas de framework, pas de script.

## L'ouvrir

Double-cliquer sur `index.html`, ou servir le dossier :

```bash
python3 -m http.server 8000
```

## Contexte

PES Dépannage est un projet entrepreneurial. Cette page est la vitrine de
présentation ; elle n'est pas connectée à un back-end, les formulaires et les
boutons d'action sont encore des maquettes.
